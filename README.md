# 3trick

A Vite + React GitHub Pages app for practicing OSRS tick manipulation patterns.

## Trainers

- 3-tick fishing (implemented)
- Additional methods listed in the menu as upcoming

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run lint
npm run build
```
